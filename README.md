This project implements a classic Chess Game using C++ and the simple, easy-to-use raylib library for graphics. The key feature is the integration of an intelligent AI opponent that utilizes the Minimax algorithm optimized with Alpha-Beta Pruning to determine its moves.
✨ Features
2D Graphics: Utilizes raylib for rendering the chessboard, pieces, and game UI.
Player vs. AI: Play against a computer opponent powered by an AI search algorithm.
Minimax Algorithm: The AI uses the Minimax search strategy to find the optimal move.
Alpha-Beta Pruning: An optimization of Minimax that drastically cuts down on the search space, improving AI move calculation time.
Basic Move Validation: Implementation of basic chess move rules (pawn, rook, knight, bishop, queen, king).
